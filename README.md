🚖 Uber Analytics Dashboard

Uber Analytics Dashboard is an interactive data analytics and business intelligence project built using Streamlit, Pandas, and Plotly. The project analyzes ride-booking data and provides insights into revenue, ride demand, customer ratings, payment methods, cancellations, and operational performance through interactive dashboards and visualizations.

✨ Features
📊 Interactive Dashboard
📂 Dataset Filtering & Search
📈 Revenue & Ride Analysis
🚕 Vehicle Performance Insights
⭐ Customer Rating Analysis
💳 Payment Method Analytics
❌ Cancellation Analysis
